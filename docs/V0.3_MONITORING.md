# SawitHeight R v0.3.0 — Monitoring Multi-Periode

## Tujuan

Menjadikan hasil tinggi pokok sebagai time-series atribut pada Shapefile sehingga analisis dapat diulang untuk monitoring pertumbuhan.

## Mode

- `first`: baseline/periode pertama.
- `monitoring`: membaca hasil SHP sebelumnya, join berdasarkan ID pokok, membawa atribut historis, dan menghitung pertumbuhan.

## ID monitoring

Output selalu menyimpan `tree_id` sebagai ID kanonik. Pada monitoring, data titik saat ini harus memiliki field ID permanen yang dapat dicocokkan dengan `tree_id` atau field ID yang dipilih pada SHP sebelumnya. Join tidak menggunakan urutan baris.

## Field periode

Shapefile/DBF membatasi nama field hingga 10 karakter. Kode periode dibatasi maksimal 3 karakter.

| Makna | Contoh D1 |
|---|---|
| tinggi rerata | `rerata_D1` |
| tinggi maksimum | `maks_D1` |
| tinggi minimum | `min_D1` |
| simpangan baku | `sd_D1` |
| piksel kanopi | `npix_D1` |
| tutupan kanopi | `cover_D1` |
| kelas tinggi | `kelas_D1` |
| status QC | `qc_D1` |
| pertumbuhan | `tumb_D2` |

Pertumbuhan periode saat ini didefinisikan sebagai:

`TUMB_Dn = MAKS_Dn - MAKS_D(n-1)`

Nilai negatif dipertahankan sebagai hasil observasi dan tidak diubah menjadi nol.

## Output utama

- `shapefile/hasil_tinggi_pokok_<PERIODE>.shp`
- `shapefile/buffer_pokok_<PERIODE>.shp`
- `tinggi_pokok_sawit_<PERIODE>.csv`
- `nCHM_sawit.tif`
- laporan dan QC lainnya.

GeoPackage tidak lagi digunakan sebagai output hasil tinggi pokok.
