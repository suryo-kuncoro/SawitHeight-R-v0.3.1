# SawitHeight R v0.2.0 — Ground Reference

Versi ini memperbarui Step 03B dari tutorial menjadi modul **Referensi Tanah Independen**.

## Mode

1. `csf_tin` — Ground dari dense cloud diklasifikasikan dengan CSF lalu normalisasi TIN langsung.
2. `external_dtm` — Menggunakan DTM independen GeoTIFF.
3. `gcp_bias` — Membuat DTM TIN dari ground CSF, membandingkan Z DTM dengan elevasi aktual GCP, menghitung mean/SD/RMSE, dan secara opsional menerapkan mean bias.
4. `gcp_anchor` — Menggabungkan ground CSF dan XYZ GCP sebagai referensi ground, membentuk permukaan TIN raster, lalu menggunakannya untuk normalisasi.

## Output tambahan pada mode GCP

`ground_reference/` berisi ringkasan JSON, DTM referensi, dan tabel/layer residual GCP.

## Catatan implementasi B.2

Tutorial menunjukkan penyuntikan GCP langsung ke point cloud. Pada aplikasi, implementasi dibuat lebih defensif: ground hasil CSF dan GCP digunakan untuk membentuk LAS ground-reference tersendiri, lalu permukaan TIN dirasterisasi sebelum dipakai untuk normalisasi point cloud utama. Ini menghindari modifikasi header/atribut LAS utama dan tetap mempertahankan fungsi GCP sebagai anchor permukaan tanah.
