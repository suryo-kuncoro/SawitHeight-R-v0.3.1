DATA UTAMA

Pilih sumber analisis

Versi MVP memproses satu file LAS/LAZ per run.

Hasil dense cloud SfM-MVS dari Metashape, Pix4D, DJI Terra, atau perangkat lunak sejenis.
Geometri wajib POINT/MULTIPOINT. CRS akan ditransformasikan ke CRS point cloud.
Step 03B: pilih referensi tanah independen bila tersedia. Mode GCP membutuhkan titik dengan elevasi tanah aktual.
Raster elevasi tanah satu band. CRS harus sama dan cakupan harus menutupi point cloud.
GCP harus POINT, memiliki CRS, dan field elevasi numerik yang merepresentasikan elevasi tanah aktual.
Aplikasi membuat subfolder run_YYYY-MM-DD... untuk setiap analisis.
Hanya dipakai jika CRS LAS/LAZ kosong.
Nama field unik dari data titik pokok.
Baseline membuat atribut periode pertama. Monitoring membawa atribut historis dari SHP sebelumnya dan menghitung pertumbuhan.
Maksimal 3 karakter agar nama field Shapefile tidak melebihi batas 10 karakter.
Digunakan untuk mencari field maks_D1 sebagai pembanding pertumbuhan.
Join monitoring dilakukan berdasarkan ID pokok, bukan berdasarkan urutan baris atau posisi geometri.
Portable self-contained akan memakai R yang dibundel; versi ringan dapat memakai instalasi R yang sudah tersedia.

KLASIFIKASI & OUTPUT

Kelas baseline, status pertumbuhan, dan file hasil

D1 memakai kelas tinggi. Mulai D2, field kelas periode berisi status pertumbuhan berdasarkan delta tinggi maksimum.

Dipakai mulai D2. Delta ≥ nilai ini = NORMAL; delta positif tetapi lebih kecil = ANOMALI; delta negatif/tidak tersedia = PERLU CEK.
File dapat sangat besar.
D1: kelas_D1 = kelas tinggi. D2+: kelas_D2 = NORMAL / ANOMALI / PERLU CEK berdasarkan tumb_D2.
